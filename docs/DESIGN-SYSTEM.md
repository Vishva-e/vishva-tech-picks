# Design system

**Brand:** Visha Tech Picks — “Smart Tech. Clear Choices.”

- Background `#f8fafd`; white surface `#fff`.
- Main text `#14213a`; secondary body `#33445f`; muted `#64748b`.
- Accent `#2563eb`; borders `#e6ecf5`.
- System-first sans serif; no third-party font request.
- Card radius around 20px; restrained shadows and blue-tinted abstract hero illustration.
- Responsive layout from mobile 320px to desktop 1180px shell.
- Keyboard focus outlines, skip link, semantic main/nav and reduced-motion preferences.
- Category and article illustrations use emoji and local CSS art; **not Amazon product photographs**.

**Review before publishing:** Contrast audit, VoiceOver/keyboard manual checks, 360px and desktop layout, content proofreading and branding approval.
